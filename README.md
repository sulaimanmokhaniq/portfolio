# Sulaiman Mokhaniq · Portfolio

Personal portfolio built with Next.js 16, TypeScript, Tailwind CSS 4 and Motion. Bilingual (English / Arabic with RTL) with light and dark mode.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 (redirects to `/en`; Arabic is at `/ar`).

## Editing content

All text, projects and experience live in `src/content/site.ts`. Each project gets its own case-study page at `/[lang]/work/[slug]`.

## Deploy

Import this repo on [Vercel](https://vercel.com/new). No environment variables are needed.
